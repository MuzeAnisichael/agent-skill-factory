# Report Consistency Checklist

| 核查项 | 对照材料 | 输出证据 |
|---|---|---|
| 单位和量纲 | 方法、表头、坐标轴、正文 | 位置、原单位、声明的换算方式 |
| 样本数与排除 | 实验记录、方法、表格 | 初始数、排除理由、最终数的对应 |
| 指标定义 | 方法、计算记录、图注 | 分母、平均方式、误差定义 |
| 数值引用 | 正文、图表、数据摘要 | 两处数值、精度、容差依据 |
| 条件一致性 | 配置、方法、记录 | 温度、时间、参数是否对应同一次实验 |
| 结论边界 | 结果、限制、讨论 | 关联/因果区分、适用条件、缺失证据 |

不要仅因作者未使用某种统计检验就要求补做；先核对研究问题、数据结构和方法声明。
报告采用缩写时，核对首次定义与后续使用是否一致，不补造术语释义。
