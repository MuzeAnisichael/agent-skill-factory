# Experiment Report Check

## Workflow

1. 获取报告正文、表格和相关实验记录，确认本次仅核查一致性还是另有统计复算授权；缺少原始数据时明确标注限制。
2. 阅读 `references/checklist.md`，建立方法、表格、图注和结论之间的证据对应，记录每个值的单位、样本数和来源位置。
3. 逐项核对正文与图表中的同一数值、单位、条件及样本量；复算时使用原始数据与作者声明的方法和容差，不能猜测统计方法。
4. 区分已确认的不一致、需要作者澄清的问题和资料不足的未验证项。结论因果性或泛化范围超出证据时说明缺少什么支持。
5. 用 `assets/review-template.md` 输出审阅记录，每条结论引用章节、表格或实验记录，不改写或填补实验结果。

## Quality Checks

- 所有问题都含来源位置、冲突证据和建议核查动作。
- 未验证项明确列出，不把“未发现矛盾”写成“研究结论正确”。
- 不添加原材料中不存在的数据、引用、实验条件或统计显著性。
- 数值容差和比较口径有依据；区分舍入差异与实际矛盾。
