# CSV Input Contract

输入是带标题行的 UTF-8 CSV，允许 UTF-8 BOM。默认逗号分隔，标题不得为空或重复。

- `--required COLUMN`：列必须存在，单元格不得仅为空白，可重复指定。
- `--numeric COLUMN`：列必须存在，值能解析为有限浮点数，NaN 和 Infinity 不通过。
- `--unique COLUMN`：列必须存在，非空值不得重复；多个参数分别检查每列，不表示组合键。
- 未声明必填的空单元格只统计，不判错；未声明唯一性的重复值允许存在。
- 所有数据行的字段数量必须与标题数量相同。空白行跳过。
- 脚本不做单位转换、日期解析、统计离群判定或领域范围判定。

行号来自 CSV 解析器的物理结束行号；多行引用字段的记录用结束行定位。
格式损坏、空文件、缺少声明列和输入读取失败返回 2。记录契约不通过返回 1。
报告 `issues` 最多保留 25 条，`issue_count` 统计全部问题。
大文件的唯一性检查需要保存已见标识，内存随不同标识数量增长。
