# Python Review Checklist

只检查与本次代码范围相关的项目。

| 范围 | 检查证据 | 最小测试方向 |
|---|---|---|
| 索引和切片 | 边界、循环终止、空序列处理 | 空输入、单元素、最后一个元素 |
| 数值计算 | 零分母、非有限数值、整数截断、容差来源 | 零值、负值、极小值、NaN/Infinity |
| 可变对象 | 默认参数、浅复制、跨调用共享状态 | 连续两次调用、嵌套结构独立性 |
| 文件与数据 | 编码、路径基准、缺失列、异常清理 | 临时目录、缺失文件、非 UTF-8 输入 |
| 研究结果 | 随机种子、训练/测试隔离、单位与量纲 | 固定种子复现、数据划分不交叠 |
| 测试有效性 | 断言是否验证行为而非复制实现 | 能失败的反例、修复前失败后通过 |

数值阈值必须来自项目规格或实验依据。不能仅凭清单替用户添加领域约束。
